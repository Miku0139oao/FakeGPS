# FakeGPS 2.2.3

自動檢查新版本，有更新時一鍵開啟下載。

## 更新檢查

- 開啟 App 時（成功查詢後 24 小時內不再查）向 GitHub 查詢最新 Release；已是最新或離線時不打擾。
- 有新版本時顯示「有新版本 X」對話框：目前版本、最新版本與更新說明摘要。**下載** 會用瀏覽器開啟 APK 下載，**版本說明** 開啟 Release 頁面。
- 同一版本按 **稍後** 之後三天內不再重複提示；發佈新版本會立即再提示一次。
- 設定 → 行為 → **檢查更新**（預設開啟）可完全關閉自動檢查；設定 → 關於 → **立即檢查** 可手動檢查，結果顯示「已是最新版本（X）」或「無法檢查更新」。

## 隱私

- 只送出 HTTPS GET 到 `https://api.github.com/repos/Miku0139oao/FakeGPS/releases/latest`，User-Agent 固定為 `FakeGPS-Android`；不帶帳號、裝置識別碼、位置或任何個人資料。
- 成功查詢後 24 小時內不再查詢；查詢失敗時保持靜默，最快一小時後才會再試，不會連續重試洗版。

## 驗證

- Android 16 x86_64 模擬器實測：自動檢查、手動檢查（已是最新）、離線失敗提示、更新對話框（2.2.2 → 2.2.3，使用正式 Release）、下載按鈕開啟瀏覽器、24 小時節流，以及關閉開關後不再送出請求。
- 單元測試 71 個，新增版本比較、Release JSON 解析（含 JSON null）、提示節流與 Markdown 清理測試。

## 其他

- 版本 2.2.3（versionCode 8）。`fake_gps.db`、`SharedPreferences` 格式未變，可直接覆蓋 2.2.x 安裝。

## 安裝

1. 下載 `FakeGPS_v2.2.3.apk`。
2. 開發人員選項 → **模擬位置應用程式** → 選 FakeGPS。
3. 授予 **位置**、**通知**、**顯示在其他應用程式上層**。
4. 在主畫面輸入座標、從地圖選點或點選書籤，按 **開始**。
