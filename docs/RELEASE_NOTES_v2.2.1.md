# FakeGPS 2.2.1

介面重做、書籤流程簡化，並記住上次使用的位置。

## 介面

- 主畫面、懸浮搖桿、選點地圖、設定頁統一為 Material 3 表面／字體／間距系統。
- 搖桿方向鍵加大到 48dp，加入震動回饋與按住連發；實測上鍵 +10 m、左鍵 −10 m，方向正確。
- 地圖選點頁：搜尋卡、置中／縮放按鈕、底部座標卡（只顯示座標，複製／外開為圖示按鈕）。
- 設定頁改為「外觀／行為／關於」三段，顯示版本與 OpenStreetMap 授權。
- **懸浮面板可關閉**：設定 → 行為 → 「懸浮面板」。部分 App／瀏覽器在偵測到疊加層時會拒絕顯示權限視窗，關閉後模擬定位照常運作，只是不再顯示懸浮搖桿。
- 停止模擬定位後留在主畫面，可直接改座標或重新開始。

## 書籤

- **一鍵儲存**：主畫面「儲存目前位置」與懸浮面板的星星按鈕都會直接儲存，不再跳出命名視窗；名稱自動使用座標，同一位置重複儲存會提示已存在。
- 每列右側 **⋮ → 重新命名／刪除**，取代原本只有長按才能刪除的手勢。
- 重新命名失敗會如實提示；名稱留空時「儲存」會停用，對話框不會把輸入清掉。
- 舊版名為「Bookmark／書籤／Lesezeichen…」的書籤，在全部 9 個語系下都會以座標顯示，不再出現一整排同名項目。
- 修正點擊書籤沒有反應的問題（列內的 clickable 攔截了觸控）。

## 定位

- 記住上次開始的位置；全新安裝且已授予位置權限時，以手機最後已知位置作為起點，不再固定顯示美國的範例座標。
- **瀏覽器定位修正**：定位引擎同時覆寫 Android 的 `fused` provider。Chrome、vivo 瀏覽器等會向 fused 要求位置的 App，現在會拿到模擬座標而不是真實位置（實機以 Chrome 與 vivo 瀏覽器驗證，每秒更新）。
- **背景執行**：設定 → 行為 →「背景執行」會依品牌開啟對應設定頁（vivo/iQOO、小米/Redmi/POCO、OPPO/realme/OnePlus、華為/榮耀、三星），其他品牌則開啟系統電池最佳化對話框。實測 vivo 設為「允許後台高耗電」後，面板關閉、螢幕關閉都能持續注入。
- 關閉懸浮面板時，不再要求「顯示在其他應用程式上層」權限。
- 支援中文輸入法打出的全形標點：`22。37139，114。17833` 可直接解析。
- 移動步長 ± 與座標格式化改用十進位運算，不再出現 `0.19999999999999996` 這類數值；步長低於 1 公尺時「−」也不會反而變大。
- 懸浮面板的提示與前景服務通知，會跟隨 App 內選擇的語言。

## 其他

- Gradle namespace 由 `com.tencent.fakegps` 改為 `com.github.fakegps`；`applicationId` 不變，既有資料與設定不受影響。
- 版本 2.2.1（versionCode 6）。`fake_gps.db`、`SharedPreferences` 格式完全未變，可直接覆蓋安裝。

## 安裝

1. 下載 `FakeGPS_v2.2.1.apk`。
2. 開發人員選項 → **模擬位置應用程式** → 選 FakeGPS。
3. 授予 **位置**、**通知**、**顯示在其他應用程式上層**。
4. 在主畫面輸入座標、從地圖選點或點選書籤，按 **開始**。
